## Что исправить

**1. Батареи.** Варианты с русской транслитерацией без префикса `/ru/` до сих пор показывают 404. Обе украинские страницы назначения открылись, имеют canonical на себя и присутствуют в текущей украинской карте сайта. Назначить два прямых постоянных перенаправления.

| Старый адрес | Назначение 301 |
|---|---|
| `/parts/vysokovoltnaia-batareia/` | `/parts/visokovoltna-batareia/` |
| `/parts/model-3-06-2017-12-2023/vysokovoltnaia-batareia/` | `/parts/model-3-06-2017-12-2023/visokovoltna-batareia/` |

В URL Inspection для первого адреса последний 404 датирован 28 октября. Google указал русскую страницу батарей как источник. Сейчас её переключатель UA и hreflang уже ведут на правильный украинский URL. В `app/Services/CatalogPath.php` уже есть нормализация для RU. Для этих двух UA-адресов достаточно точечного правила с сохранением модели. При приёмке проверить один переход, конечный ответ 200, ссылки UA/RU и отсутствие старых адресов в sitemap.

**2. Товарные 404.** Из 60 примеров GSC проверены все 59 публичных адресов. Оставшийся `/lead/callback` — обработчик отправки формы методом POST. На 52 адресах браузер показал страницу 404, ещё 7 открылись. Среди семи есть контакты, политика конфиденциальности, СТО и числовые адреса товаров 77120 и 108973, которые теперь ведут на карточки с артикулом. Ни один из 60 исходных адресов не найден в трёх текущих sitemap.

Среди 52 страниц с 404 — **39 товарных URL для 31 отдельного ID**. По публичным данным причина отсутствия конкретного товара не установлена. Сверить эти ID с публичностью карточки и складским источником. Для доступного товара восстановить выдачу из storefront API и ссылку каталога. При переносе на другой ID сопоставить тот же экземпляр и поставить 301. Для удалённого товара без эквивалента сохранить 404 и убрать актуальные битые внутренние ссылки. Продажа сама по себе не повод удалять карточку. Например, для `/ru/parts/104743/` Google указал как источник каталог Highland. На проверенной первой странице этого каталога ссылки на 104743 уже нет.

**3. Обнаруженные товары.** На эту группу приходится 386 из 421 исключённых отправленных URL. Для кронштейна `1002322-00-C` (ID 113428) в индивидуальной проверке Google сообщает «URL неизвестен Google», даты обхода нет. На сайте товар есть в наличии, обе языковые версии присутствуют в соответствующих текущих sitemap, проверенная UA-карточка открывается с canonical на себя. Для этой карточки и других приоритетных товаров в наличии стоит проверить путь от модели и категории до товара по обычным ссылкам, включая пагинацию. Там, где путь отсутствует, добавить ссылку из подходящей категории. Для артикула `1100671-00-D` (ID 113507) сводка ещё показывает «просканирована, не проиндексирована», но индивидуальная проверка уже подтверждает индексирование. Вести контроль по конкретным URL и датам обхода.

## Где исправления уже видны

**Серверные ошибки.** Все 13 примеров открылись в браузере с содержимым соответствующих категорий, страниц пагинации или товаров. Для `/parts/?page=110` последний зафиксированный сбой у Googlebot был 19 октября. Live Test Google 31 октября успешно получил страницу, сканирование и индексирование разрешены. Проверка исправления начата 26 октября, в подробностях 13 ожидают и 0 не прошли проверку. Две карточки из отправленных URL — ID 98083 и 107015 — тоже открываются. Это проверка доступности в момент обращения. При новом 5xx нужно сопоставить URL и время сбоя с публичным журналом запросов хостинга и ответом API склада, отдельно проверить тайм-ауты и доступность последней сохранённой версии каталога.

**Дубли.** У двух исключённых отправленных категорий — «Внутрішнє оздоблення» и «Компоненти закриття» — Google выбрал старые пути `/parts/category/…` при обходе 18–19 сентября. Оба этих адреса сейчас ведут на чистые адреса категорий с canonical на себя. Аналогично у «Задних полуосей» Google 17 октября выбрал родительский адрес, который сегодня ведёт на выбранный сайтом конечный раздел. Для этих примеров сохранить направление редиректов и отслеживать следующий обход. Перед изменениями остальных пар проверить выбранный Google адрес, язык страницы, модель и фактический набор товаров.

**Обновлённые услуги.** UA-страница ремонта платы и процессора есть в индексе, выбранный Google canonical совпадает с адресом страницы. Последний обход в индивидуальной проверке датирован 27 сентября. Эти данные ещё не показывают эффект публикации 30 октября.
