## Батарея: причина и подготовленное исправление

Снимок 27.10 «10 против 2» исторический. Повторная проверка 29.10 показала:

| Локаль и API category_path_slug | Полный набор |

| RU `visokovoltna-batareia--vysokovoltnaia-batareia` | 3 ID |
| RU `vysokovoltnaia-batareia--vysokovoltnaia-batareia` | 8 ID |

Два RU-набора не пересекаются; их объединение совпадает с UA. Источник — [battery-current.json](seo-package2-2026-10-29-sources/battery-current.json), три последовательных ответа 200 с полной первой страницей.

Причина: для части Model S локализованное название корня RU отсутствует, и presenter использует украинский fallback. Query фильтровал точную строку/slug, разделяя один ассортимент на два корня. Сопоставление языкового пути по первому товару также зависело от выбранного подмножества. Потери складских записей не обнаружено.

Опубликованный backend нормализует **только точный украинский fallback корня батареи в RU-представлении** и его первый slug-сегмент. Старые query aliases остаются совместимыми; нижние уровни, ID и физическая таксономия не меняются. Нормализация применяется к чтению старых available/sold snapshots в памяти и новым row-представлениям. Raw snapshots и БД не переписываются; дополнительных HTTP-запросов при render не появляется.

Зависимый frontend overlay согласует RU canonical/hreflang, старые URL→301, HTML/schema breadcrumbs, модельные ссылки и sitemap. Меняет только собственные версии catalog/AJAX/product/sitemap cache keys, без добавления общего flush в код. Он не входил в независимый frontend payload и опубликован отдельно после проверки backend.
