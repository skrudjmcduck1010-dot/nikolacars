## Канонические категории

Добавлена ограниченная карта **4 групп / 8 локализованных parent → leaf алиасов**.
Для каждой пары 27.10 выполнены последовательные read-only запросы каталога:
HTTP 200, page=1, per_page=100, last_page=1, число уникальных IDs равно total.
Сравнивались полные непустые множества IDs, а не только счётчики. У четырёх
принятых групп совпали также множества UA/RU. Предпочтён существующий глубокий
URL; для педали Model 3 его уже выбрал Google по данным инспекции GSC.

|---|---|---:|---|
| Model 3 06.2017–12.2023 | `galma/pedal-galma` / `tormoza/pedal-tormoza` | 2 | Добавить ещё `/pedal-galma` / `/pedal-tormoza` |
| Все модели, педаль | `galma/pedal-galma` / `tormoza/pedal-tormoza` | 8 | Добавить ещё одноимённый последний сегмент |

Префикс UA — `/parts/`, RU — `/ru/parts/`; модель добавляется после префикса,
когда указана в таблице. Официальные категории/ID не изменялись. `normalize()`
сохраняет повторяющиеся официальные уровни; глобального схлопывания slug нет.
Родители возвращают 301 непосредственно на выбранный leaf, включая legacy
`subcategory/` URL. Query string сохраняется. Внутренние ссылки SSR/JS,
canonical/hreflang и хлебные крошки HTML/JSON-LD согласованы с картой;
дублированный пункт крошек удалён. Циклов на принятых целях в fixtures нет.

В parts sitemap эти глубокие категории до изменения не включались; его состав
и cache key v9 сохранены. Нельзя утверждать, что все 32 исключения GSC устранены:
Google должен повторно обойти изменения, а остальные случаи не вошли в карту.

**Исключение — батарея.** Проверены точные пути без модели:

- UA `/parts/visokovoltna-batareia/visokovoltna-batareia/` и тот же путь
  с дополнительным `/visokovoltna-batareia/`: полные одинаковые 10 IDs.
- RU `/ru/parts/visokovoltna-batareia/vysokovoltnaia-batareia/` и тот же путь
  с дополнительным `/vysokovoltnaia-batareia/`: полные одинаковые 2 IDs.

API объявляет эти UA/RU пути локализованной парой, но ассортимент различается.
Они сознательно исключены из новой карты. Следующий шаг — выяснить причину
локализованного отбора/таксономии, прежде чем согласовывать hreflang и redirect.
Это отдельная задача: в этом пакете склад и бизнес-данные не менялись.

Из текущего seo-index найдены 120 UA и 116 RU кандидатов «родитель с единственным
одноимённым потомком». Наличие такой структуры само по себе не доказывает
равенство ассортимента: у родителя могут быть собственные товары. Двадцать
точечных GET покрыли только пять групп выше. Массовой проверки 236 веток нет.

## Каталоги, News и названия услуг

Для Model 3 2017–2023 и Model Y 2020–2025 в UA/RU добавлены предметные title,
description и H1, например «Запчастини Tesla Model 3 2017–2023 у Києві».
Короткое вступление поясняет точный период каталога, поиск по артикулу и проверку
ревизии/стороны/разъёмов/VIN. Совместимость всей модели не обещается.
Есть ссылки только на разделы с count > 0; Model 3 содержит ссылку на Highland,
если тот присутствует в списке моделей. Вступление показывается на первой
странице без поисковых/сортировочных параметров. JS сохраняет новые title/H1;
пагинация сохраняет номер страницы и собственный canonical, поиск/сортировка —
noindex и canonical основного раздела.

Пустые `/news/` и `/ru/news/` остаются доступны напрямую с локализованным
законченным сообщением и ссылками на услуги/каталог. Они получили noindex, follow,
удалены из навигации и pages sitemap (114 URL вместо 116). Cache key только
pages sitemap поднят v1 → v2; общего сброса кэшей нет.

В `targeted_services.php` название навигации согласовано без обещания FSD;
название программирования ключей оставлено общим, поскольку услуга шире карты.
Сервисные изменения описаны отдельно в
[отчёте контента](seo-service-content-2026-10-27.md): пять приоритетных шаблонов
и очистка MCU/camera/CCS, всего восемь шаблонов UA/RU; удалены 12 редакторских
абзацев и исправлены пять предложений. Это часть того же разрешённого пакета.
